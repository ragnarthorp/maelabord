# Mælaborð

„Hver er staðan?“ Fimmtíu mælar í anda Kurzgesagt sem sýna stigasöfnun hópa. Hver mælir er með raðnúmeri, fjögurra stafa kóða og 25 ljósum frá rauðu (1) upp í grænt (10). Skjárinn sýnir klukku og dagsetningu og hvenær stig verða næst uppfærð, á heila tímanum frá 10:00 til 14:00.

## Notkun

Opnaðu `index.html` í vafra.

- **K** opnar stjórnborð kennara.
- **1–6** skipta milli klukkan 09:00 og 14:00.
- Á stjórnborðinu skráir kennarinn fjölda ljósa (0–25) fyrir mæla hópanna 25. Autt reitur heldur gildinu frá síðasta klukkutíma.
- Hinir 25 mælarnir breytast sjálfkrafa á heila tímanum.

Þegar síðan er opnuð beint úr þessu repo-i vistast gögnin aðeins í vafranum sem þau voru skráð í.
